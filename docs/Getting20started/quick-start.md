Use this quick start to set up TestPartner and find the resources you need for your first integration.

## Prerequisites

1. Sign in to your TestPartner account.
2. Confirm you have access to the workspace or project you want to use.
3. Ask your administrator for any credentials required by your organization.

## Quick start

1. **Open your workspace**

   Select the workspace or project where you want to configure TestPartner.

2. **Review your integration options**

   Open the API Reference from the navigation to see available endpoints, request formats, and responses.

3. **Prepare your credentials**

   Store credentials securely using your team’s approved secrets manager or environment configuration. Do not commit credentials to source control.

4. **Make a test request**

   Use the API Reference to copy a request example, then run it in your development environment.

5. **Check the response**

   Confirm the request returns a successful response before using it in your application.
